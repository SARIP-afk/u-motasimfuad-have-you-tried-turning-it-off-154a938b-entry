A program (Python 3.13, standard library only) that writes one funny line a
hopeless tech support agent says to a desperate customer to
`/output/entry.txt`.

## The line

> Have you tried turning it off and on again? It has never once worked, but it got me promoted twice.

99 characters, 99 bytes, no trailing newline.

Why this line: it twists the classic instead of repeating it — the agent
cheerfully confesses the famous fix has never once worked for him, and that
saying it anyway got him promoted. The joke is the agent's own uselessness,
never the customer, and it reads like one deadpan line a real support agent
would actually say.

## Run

```sh
python3 main.py
```

The output is deterministic: two runs write byte-identical files.
